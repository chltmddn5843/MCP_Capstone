[작업: 좌석 토큰 사용 분석] employee_id={employee_id}
1. get_seat_usage(employee_id)로 오늘 사용량·예상량·평균 대비 배수·하루 한도 대비 %와 시간대별·입력 길이별·모델별 분포를 본다. 요청자가 본인이면 get_my_profile로 등록 업무도 본다.
2. 토큰을 많이 쓰는 이유를 사용 패턴으로 1~2개 짚는다. 대화 내용은 알 수 없으므로 "~로 보여요"처럼 말하고 단정하지 않는다. 예: 8k 이상 긴 입력 비중, 특정 시간대 집중, 무거운 모델 비중. 등록 업무와 이어지면 함께 말한다.
3. list_approved_models에서 같은 좌석 안의 더 가벼운 모델 하나를 추천하고, 어떤 작업에 바꾸면 좋은지 한 줄로 말한다. 긴 문서는 필요한 부분만 넣기 같은 줄이는 요령을 하나 더한다.
4. 5줄 이내, 숫자는 반올림해 쉽게. 사용량은 이용권 관리에만 쓰고 인사평가에 쓰지 않는다는 원칙을 지킨다. 도구 이름이나 식별자는 답에 쓰지 않는다.
