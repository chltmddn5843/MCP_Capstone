승인 기준 (에이전트가 만드는 처리 요청은 모두 관리자 승인을 거친다. 이용권 추가 구매는 하지 않는다)
| 처리 요청 | 단계 | 누가 | 처리 |
| 활용 제안 발송 | 자동 | 알림 정책 | 사람 승인 없음 |
| 이용권 배정 (seat_assign) | 담당자 승인 | 관리자 | 남은 좌석 있음: 승인 뒤 배정 / 없음: 승인 불가, 반려 (추가 구매 없음) |
| 이용권 반납 (seat_reclaim, 직원 본인) | 자동 | 시스템 | 바로 회수 (관리자 승인 없음) |
| 이용권 회수·재배정 (seat_reclaim, 관리자) | 담당자 승인 | 관리자 (회수는 본인 확인 응답 필수) | 승인 뒤 실행 |
| API 제품 사용 신청 (api_access) | 담당자 승인 | 관리자 | 승인 뒤 프로젝트 생성 |
| 테스트 환경 모델 변경 (model_change, test) | 담당자 승인 | 관리자 | 승인 뒤 실행 |
| 운영 환경 모델 변경, 신규 제품 도입 (purchase_review, model_change prod) | 책임자 결정 | 관리자 | 결정만 기록, 실행은 시스템 밖 |
