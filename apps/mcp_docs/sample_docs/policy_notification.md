## 제1조 대상
업데이트 활용 제안은 관련 업무를 직접 등록한 직원에게만 보낸다. 모든 업데이트를 전 직원에게 보내지 않는다.

## 제2조 승인
개인 대상 제안은 초안으로 저장한 뒤 정책에 따라 보낸다. 팀·전사 대상 공지는 HRD 승인 후 보낸다.

## 제3조 빈도
직원 1인당 주 2건을 넘지 않는다. 20시부터 다음 날 8시까지는 보내지 않는다.

## 제4조 내용
제안에는 바뀐 기능, 해당 업무에 도움이 되는 이유, 사용 예시, 적용 조건, 공식 원문 링크를 넣는다.
직원은 '도움 됨 / 관련 없음 / 적용 방법 질문'으로 반응하고, 반응은 다음 제안에 반영한다.
