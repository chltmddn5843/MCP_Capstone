> 설계 문서 9절 초기값이다. 에이전트 쪽 사본(apps/agent_runtime/prompts/policy_notification.md)과 같은 값을 쓴다. 값이 바뀌면 두 곳을 함께 고친다.

## 제1조 대상과 발송 조건
업데이트 활용 제안은 관련 업무를 직접 등록한 직원에게만 보낸다. 모든 업데이트를 전 직원에게 보내지 않는다.
에이전트가 관련 업무 근거를 제시한 경우에만 보낸다. 근거 없는 제안은 보내지 않는다.

## 제2조 승인
개인 맞춤 제안은 이 정책 범위에서 자동으로 보낸다. 팀·전사 공지는 HRD가 초안을 승인한 뒤 보낸다.

## 제3조 빈도와 시간
개인 제안은 1인당 주 2건을 넘지 않는다. 발송 시간은 평일 09:00~18:00이다.

## 제4조 관련 없음 반응
같은 도구 카테고리 제안에 '관련 없음'이 2회 연속이면 해당 직원에게 4주 동안 그 카테고리 제안을 보류한다.

## 제5조 내용
제안에는 등록 업무 이름, 바뀐 기능 한 줄, 업무용 요청 예시 1개, 적용 조건(플랜), 공식 원문 링크를 넣는다.
직원은 '도움 됨 / 관련 없음 / 적용 방법 질문'으로 반응하고, 반응은 다음 제안에 반영한다.

## 제6조 사용 의사 확인
저사용 이용권 소유자에게 보내는 사용 의사 확인의 응답 기한은 5영업일이다.
무응답이면 이용권을 유지하고 담당자에게만 알린다. 무응답은 회수 사유가 아니다.

## 제7조 수신 거부
직원은 활용 제안 수신을 끌 수 있다.
