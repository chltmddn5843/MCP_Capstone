## 제1조 목적
임직원이 생성형 AI 도구를 안전하고 효율적으로 쓰도록 기준을 정한다.

## 제2조 승인 도구
회사가 승인한 도구와 모델만 업무에 쓴다. 승인되지 않은 도구는 비교 검토 대상일 뿐 업무에 쓰지 않는다.

## 제3조 입력 금지 정보
고객 개인정보, 주민등록번호, 계좌번호, 미공개 재무 정보는 입력하지 않는다.
도구마다 허용 데이터 등급(public, internal, confidential)을 넘는 자료는 넣지 않는다.

## 제4조 사용 현황 확인
개인 사용량은 본인과 이용권 관리 목적으로만 본다. HRD는 팀 단위 지표만 보며, 5명 미만 팀은 집계에서 뺀다.

## 제5조 모델 선택
API 업무는 품질 기준을 통과한 모델 중 비용이 낮은 모델을 쓴다. 평가 결과가 없으면 샘플 평가를 먼저 한다.
정액 좌석제 도구는 모델을 바꿔도 청구액이 바뀌지 않는다.

## 제6조 이용권 회수
마지막 사용일만으로 회수하지 않는다. 기록이 없으면 '확인 필요'로 보고 본인에게 사용 의사를 묻는다.
휴직자와 최근 입사자는 회수 대상에서 뺀다.

## 제7조 예산
API 프로젝트마다 월 예산을 둔다. 일 비용이 평소의 3배를 넘으면 경보를 띄운다.
예산 증액은 사용 목적을 확인한 뒤 자산관리팀이 검토한다.
