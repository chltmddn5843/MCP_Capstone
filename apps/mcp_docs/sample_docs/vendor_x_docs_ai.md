> 공식 모델 문서 링크를 기준으로 한 개발용 비교 후보다. 현재 회사 카탈로그에서는 계약 전 검토 상태다.

## 계약서 버전 비교
계약서 두 버전을 올리면 조항별 추가, 삭제, 변경 내용을 표시한다.
변경된 조항마다 위험도 메모를 붙인다.

## 요금
Grok 4.7은 입력 100만 토큰당 2달러, 출력 100만 토큰당 6달러를 기준으로 한다.
